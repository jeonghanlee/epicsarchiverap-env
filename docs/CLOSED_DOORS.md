# Closed doors

Candidates that a review examined and the owner decided to leave unchanged, or to settle with a comment, a test, a launcher warning or a document sentence. Each row records the verdict, the premise that explains why the state is as it is, the evidence to re-check, and the carrying commit. A later review reads this page before it opens the same candidate again.

The verdict `Keep` means the state stays as it is. `Keep, text added`, `Keep, comment added`, `Keep, test extended` and `Keep, warning added` mean that the state stays and that the named addition documents it, tests it or reports it. The column Carrying commit names the commit whose state the verdict examined. A comment, test, sentence or warning that a row cites may have been added by an earlier commit, and `git show <commit>:<path>` shows the cited text at that commit. A negative claim (no file reads, no command calls) comes with the `git grep` command that prints the hits; run it at the carrying commit.

A row is not work. The work register in `docs/milestone-9576820.md` holds the work.
